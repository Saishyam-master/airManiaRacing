# Air Mania Racing 🛩️

A Three.js-based 3D aircraft racing game featuring realistic flight physics and immersive racing environments.

## 🎮 Features

- **Realistic Flight Physics**: Quaternion-based aircraft rotation with authentic banking dynamics
- **Enhanced Banking System**: Coordinated turns with proper visual banking
- **Advanced Crash System**: Multi-point collision detection with particle effects
- **Racing System**: Complete lap timing and checkpoint system
- **4x Scaled World**: Massive terrain for immersive flight experience

## 🚀 Play the Game

1. Clone the repository
2. Run `npm start` or open `index.html` in a modern web browser
3. Click "Start Game" and enjoy flying!

## 🎯 Controls

- **W/S**: Throttle control
- **A/D**: Banking (turns)
- **Arrow Keys**: Pitch control
- **R**: Reset aircraft
- **Space**: Boost

## 🛠️ Technical Stack

- **Three.js**: 3D graphics and physics
- **JavaScript ES6+**: Modern web development
- **WebGL**: Hardware-accelerated rendering
- **AI-Assisted Development**: Built with ChatGPT, GitHub Copilot, and CodeRabbit
